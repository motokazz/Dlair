目的: パンズーム

済:
- 動画パネルと UI に付ける、パンとズームだけのコンポーネントとして UiPanZoom を追加した
- ドラッグでパンし、ホイールとピンチでズームする。ダブルクリックと有効化時に、位置と倍率を初期状態へ戻す
- 対象は複数の RectTransform。空ならこのオブジェクト自身。以前の単一 target は引き継ぐ
- パン範囲は Cover と Contain。基準、範囲、遊びを指定できる
- 対象のスケールが 0 のときは初期倍率を 1 にする。CanvasScaler は動かさない
- ボタンとトグルの上では、指定時間の長押しでパンし、それより前に離すとボタンが動作する。スライダーとスクロールバーではパンしない
- ホイールは、スクロールビューなど別のホイール処理の上ではズームしない
- Summary を明記し、インスペクタに出した
- パンに使うマウスボタンを、左・右・中から選べるようにした。未設定の既存データは左のまま。タッチのドラッグはボタン設定に関係なくパンする
- ダブルクリックリセットは、パンに設定したマウスボタンでのみ動作する
