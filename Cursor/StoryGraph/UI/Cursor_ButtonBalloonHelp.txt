目的: ボタンに付けて、カーソルを重ねたときに文章のバルーンを出すコンポーネントを作る

済:
- ButtonBalloonHelp を追加した。ボタンの Image と同じオブジェクトに付ける
- カーソルを重ねているあいだ、文章をボタンの上のバルーンに出す。文章が空なら出さない
- 画面上のバルーンは1つ。フォント、色、余白、位置のずれ、最大幅はボタンごと
- バルーンの地は実行時の白い画像。Unity の内蔵スプライトは使わない
- バルーンはレイキャストしない。端では画面内に収め、矢印はボタンの上を指す
- 出すまでの秒をボタンごとに持てるようにした。0 ならすぐ出す。離れると待ちの途中でも閉じる

未:

触るファイル:
- Assets/Dlair/StoryGraph/Scripts/UI/ButtonBalloonHelp.cs

決めたこと:
- コンポーネント名は ButtonBalloonHelp。Add Component は UI/Button Balloon Help
- ボタンの Image と同じオブジェクトに付ける。文章はそのコンポーネントに書く
- 表示はゲーム実行中だけ。カーソルを重ねてから、そのボタンの秒数が過ぎて出す。0 ならすぐ出す
- 待ちは時間停止中も進む。カーソルが離れたら、待ちの途中でも閉じる
- 文章が空、または空白だけなら出さない
- バルーンはボタンの上に1つだけ。複数ボタンで共有する
- 出すまでの秒、フォント、文字色、背景色、余白、位置のずれ、最大幅はボタンごとに持つ
- 地は実行時に作る白い画像。Unity の内蔵スプライトは使わない
- バルーン自身はレイキャストしない
- 画面端ではキャンバス内に収める。横にずれたときは、矢印だけボタンの上を指す
- 既存のボタンやプレハブには付けない
