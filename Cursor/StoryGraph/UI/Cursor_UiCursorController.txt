目的: カーソルオーバー対象のボタンに属性を付け、その属性に応じたカーソル画像へ切り替える

済:
- UiCursorController を追加した。押せるボタンの上で、カーソル画像を変える
- 判定はレイキャスト。透明なボタンでも、押せる Button の上なら変える。押せないボタンでは変えない
- 通常は、画像が空なら OS の矢印。ボタンオーバーの画像が空なら、内蔵の白いポインター
- 表示は UI 描画と、OS カーソルの置き換えを選べる。初期は UI 描画。UI 描画のカーソル自身はレイキャストしない
- スプライトとテクスチャの両方を受け付ける。両方あるときはスプライトを優先する
- 先端は、スプライトなら Pivot。Override Hotspot をオンにすると数値を使う
- 色と大きさは、ボタンオーバーのソフトウェア表示に使う。大きさは OS カーソルには影響しない
- Button 以外の Selectable は、Include Other Selectables をオンにしたときだけ対象にする
- 無効化したときは、OS カーソルへ戻す
- ボタンにカーソル属性 UiCursorAttribute を1つ付けられるようにした。ボタンと同じオブジェクトに付ける
- UiCursorController に、属性名ごとのカーソル画像を登録できるようにした
- オーバー中は、手前にある押せるボタンの属性に対応する画像へ切り替えるようにした
- 属性が無いボタンは、今のボタンオーバー画像のままにした
- UiCursorAttribute を別ファイルにした。Add Component の UI/Ui Cursor Attribute からボタンへ付けられる
- スライダーとスクロールバーの上では、奥のボタンのカーソル属性を見ない。手前の操作を優先する

未:

触るファイル:
- Assets/Dlair/StoryGraph/Scripts/UI/UiCursorController.cs

決めたこと:
- 属性コンポーネントは UiCursorAttribute.cs に置く。ファイル名とクラス名を揃えて、Add Component に出す
- 同じ属性名のボタンは、同じカーソル画像になる。ボタン側は属性名を選ぶだけ
- 属性と画像の対応は UiCursorController に置く。各属性はスプライト、テクスチャ、ホットスポットを持つ
- スプライトを優先する。先端は、その属性のスプライトなら Pivot。Override Hotspot がオンのときは、その属性の数値を使う
- 色と大きさは、今の Hover Tint と Hover Display Size を共通で使う
- 属性の画像が空、またはボタンの指す名前がリストに無いときは、今のボタンオーバー画像を使う。それも空なら内蔵ポインター
- ボタンの外は、今の通常カーソルのまま
- 押せないボタンでは変えない。UI 描画か OS 置き換えかも、今の設定のまま
- 重なったときは、今と同じく手前の押せるボタンを見る
- スライダーとスクロールバーが手前にあるときは、奥のボタンへカーソルを切り替えない
- 既存のボタンへ属性を一括では付けない。UI調整デバッグでは、ボタン1つずつ属性を変え、空なら外し、書き戻しで元プレファブへ書く

- 既存のプレハブとシーン
- 既存の .meta
- Assets/Dlair/StoryGraph 以外
